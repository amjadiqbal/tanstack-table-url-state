# TanStack Table URL State: URL search params and CSV/XLSX export for TanStack Table v9

`@amjadiqbal/tanstack-table-url-state` keeps a TanStack Table v9 table's sorting, column filters,
global filter, pagination and column visibility in the URL, with a TanStack Router adapter and a
plain `URLSearchParams` fallback. It also exports the current view to CSV, with XLSX as an optional
lazy-loaded entry.

> **Status:** in development. Nothing is published to npm yet.
